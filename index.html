Principes UX (mobile-first)

  • Header sticky agissant comme hub corporate (logo gauche, nav centrale, CTA "Espace client" à droite).

Interaction : au hover ou focus, la classe is-active se déplace et déclenche l'animation d'expansion, tandis que le texte vertical disparaît pour laisser place au contenu complet.

Exemple de code (structure + transition CSS + pseudo-code GSAP Flip)

<div class="hero-strips">
  <article class="strip home" data-theme="home">...</article>
  <article class="strip pro" data-theme="pro">...</article>
  <article class="strip agri" data-theme="agri">...</article>
</div>

// JS : déplacer .is-active
const strips = document.querySelectorAll('.strip');
strips.forEach(strip => {
  ['mouseenter','focus'].forEach(evt => strip.addEventListener(evt, () => activate(strip)));
});

function activate(target) {
  strips.forEach(s => s.classList.toggle('is-active', s === target));
}

/* Variante GSAP Flip pseudo-code */
const state = Flip.getState('.strip');
activate(target);
Flip.from(state, {
  duration: 0.55,
  ease: 'expo.out',
  absolute: true,
  nested: true
});

SEO & migration

Analyse des risques SEO et préservation des mots-clés métiers

  • Redirections 301 : cartographier toutes les anciennes URLs produit (ex. /tapis-logette) vers les nouvelles pages solutions AGRI pour conserver l'autorité et les backlinks.
  • Clusters sémantiques : maintenir des pages de contenu longue traîne par univers (glossaire, guides) intégrant les termes métier comme « tapis logette », « rideau souple », « porte rapide ».
  • Données structurées : balisage schema.org Product/Service pour les solutions phares et FAQ pour capter les requêtes "comment" ou "quel coût".
  • Performance : images de croquis compressées (SVG/PNG optimisé) et lazy-loading pour préserver le LCP malgré l'accordéon visuel.
  • Suivi : plan de tags Search Console avec rapports par DAS pour mesurer la récupération du trafic post-migration.
