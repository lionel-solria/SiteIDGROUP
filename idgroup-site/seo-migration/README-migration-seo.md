# Migration SEO

Ce dossier contient les éléments préparatoires pour un futur mapping 301 lors d'une refonte.

- `redirect-map.csv` : placeholder listant les anciennes URLs et les cibles.
- Process recommandé : auditer les anciennes URLs, compléter le CSV, vérifier les codes de réponse.
- Sur un hébergement statique, les redirections seront gérées côté CDN ou serveur.
