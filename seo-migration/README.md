# Préparation migration SEO

1. Compléter `url-inventory.csv` avec toutes les URLs existantes (crawl + logs).
2. Associer chaque ancienne URL à la page la plus pertinente dans `redirect-map.csv`.
3. Déployer les 301 au niveau reverse-proxy / CDN.
4. Tester les redirections et monitorer Search Console post-migration.
